# Check for a key in names of rglactions.

Check for a key in names of rglactions.

## Usage

``` r
rglactions.has.key(rglactions, key)
```

## Arguments

- rglactions, :

  named list. A list in which the names are from a set of pre-defined
  actions, see
  [`rglactions`](https://dfsp-spirit.github.io/fsbrain/reference/rglactions.md).
  The values can be used to specify parameters for the action.

## Value

logical, whether the
[`rglactions`](https://dfsp-spirit.github.io/fsbrain/reference/rglactions.md)
instance has the requested key as a name.
