# Select a single frame (3D volume) from a volume array.

Select a single frame (3D volume) from a volume array.

## Usage

``` r
vol.select.frame(volume_data, frame = 1L)
```

## Arguments

- volume_data:

  numeric array, 3D or 4D.

- frame:

  integer scalar, the frame index (1-based).

## Value

numeric 3D array.
