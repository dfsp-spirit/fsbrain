# Check whether x is a hemilist

A hemilist is a named list with entries 'lh' and/or 'rh', see
[`hemilist`](https://dfsp-spirit.github.io/fsbrain/reference/hemilist.md).

## Usage

``` r
is.hemilist(x)
```

## Arguments

- x:

  any R object

## Value

whether 'x' is a hemilist
