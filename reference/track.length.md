# Compute the total length of a path given by the coordinates of its points.

Compute the total length of a path given by the coordinates of its
points.

## Usage

``` r
track.length(point_coords)
```

## Arguments

- point_coords:

  n x 3 numerical matrix of 3D point coordinates, in the order of
  traversal.

## Value

float, the sum of the length of all segments of the path.
