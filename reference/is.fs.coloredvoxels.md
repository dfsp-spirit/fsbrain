# Check whether object is an fs.coloredvoxels instance (S3)

Check whether object is an fs.coloredvoxels instance (S3)

## Usage

``` r
is.fs.coloredvoxels(x)
```

## Arguments

- x:

  any `R` object

## Value

TRUE if its argument is a fs.coloredvoxels instance (that is, has
"fs.coloredvoxels" among its classes) and FALSE otherwise.
