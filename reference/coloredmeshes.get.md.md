# Retrieve metadata from hemilist of coloredmeshes.

Retrieve metadata from hemilist of coloredmeshes.

## Usage

``` r
coloredmeshes.get.md(coloredmeshes, mdname)
```

## Arguments

- coloredmeshes:

  hemilist of coloredmeshes

- mdname:

  the key in the named metadata list

## Value

the metadata value at the given key/mdname
