# Shift hemis apart if indicated in rglactions

Shift hemis apart if indicated in rglactions

## Usage

``` r
shift.hemis.rglactions(coloredmeshes, rglactions)
```

## Arguments

- coloredmeshes:

  hemilist of coloredmeshes

- rglactions:

  the
  [`rglactions`](https://dfsp-spirit.github.io/fsbrain/reference/rglactions.md),
  a named list as passed to functions like vis.subject.morph.native.

## Value

hemilist of coloredmeshes, the coordinates may or may not have been
shifted, depending on the
[`rglactions`](https://dfsp-spirit.github.io/fsbrain/reference/rglactions.md).
