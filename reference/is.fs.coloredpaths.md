# Check whether object is an fs.coloredpaths instance (S3)

Check whether object is an fs.coloredpaths instance (S3)

## Usage

``` r
is.fs.coloredpaths(x)
```

## Arguments

- x:

  any `R` object

## Value

TRUE if its argument is an fs.coloredpaths instance (that is, has
"fs.coloredpaths" among its classes) and FALSE otherwise.
