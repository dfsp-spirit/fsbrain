# Apply data transformation rglactions.

Apply data transformation rglactions.

## Usage

``` r
rglactions.transform(measure_data, rglactions)
```

## Arguments

- measure_data:

  numeric vector, or hemilist of numeric vectors. The data, usually
  vertex-wise morphometry data.

- rglactions:

  named list, passed as parameter
  '[`rglactions`](https://dfsp-spirit.github.io/fsbrain/reference/rglactions.md)'
  to functions like
  [`vis.subject.morph.native`](https://dfsp-spirit.github.io/fsbrain/reference/vis.subject.morph.native.md).

## Value

the transformed data
