# Retrieve combined data range from hemilist of coloredmeshes.

Retrieve combined data range from hemilist of coloredmeshes.

## Usage

``` r
coloredmeshes.combined.data.range(coloredmeshes)
```

## Arguments

- coloredmeshes:

  hemilist of coloredmeshes

## Value

numeric vector of length 2, the finite data range
