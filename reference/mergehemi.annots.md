# Merge the annotations from two hemispheres into one annot.

Merge the annotations from two hemispheres into one annot.

## Usage

``` r
mergehemi.annots(lh_annot, rh_annot)
```

## Arguments

- lh_annot, :

  annot. An annotation, as returned by
  freesurferformats::read.fs.annot().

- rh_annot, :

  annot. An annotation, as returned by
  freesurferformats::read.fs.annot().

## Value

annot, the merged annotation.
