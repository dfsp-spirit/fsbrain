# Check whether a matrix is a valid point matrix for coloredpaths.

Check whether a matrix is a valid point matrix for coloredpaths.

## Usage

``` r
check.segment.points(x, arg_name)
```

## Arguments

- x:

  the object to check.

- arg_name:

  character string, the name of the parameter, used in error messages.

## Value

an (n, 3) numeric matrix.
