# Apply a boundary box to a volume, returning the inner volume part

Apply a boundary box to a volume, returning the inner volume part

## Usage

``` r
vol.boundary.box.apply(volume, bbox)
```

## Arguments

- volume:

  a 3D image volume

- bbox:

  the boundary box

## Value

a 3D image volume, the inner volume part, resulting from the application
of the boundary box
