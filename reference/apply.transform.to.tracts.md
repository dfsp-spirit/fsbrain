# Apply a 4x4 transformation matrix to tracts.

Apply a 4x4 transformation matrix to tracts.

## Usage

``` r
apply.transform.to.tracts(tracts, transform_matrix)
```

## Arguments

- tracts:

  an `fs.tracts` instance.

- transform_matrix:

  a 4x4 numeric matrix.

## Value

the `fs.tracts` instance with transformed coordinates.
