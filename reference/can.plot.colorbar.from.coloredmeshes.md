# Determine whether colorbar can be plotted with given coloredmeshes.

Determine whether colorbar can be plotted with given coloredmeshes.

## Usage

``` r
can.plot.colorbar.from.coloredmeshes(coloredmeshes)
```

## Arguments

- coloredmeshes:

  hemilist of coloredmeshes

## Value

logical, whether the metadata suffices to plot a colorbar
